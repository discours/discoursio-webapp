## 🎯 Система обработки изображений

Приложение использует гибридную архитектуру для оптимизации изображений и медиафайлов.

### 🏗️ Архитектура обработки

| Компонент | Назначение | Технология |
|-----------|------------|-------------|
| **Загрузка файлов** | Пользовательский контент | Квотер API |
| **Оптимизация** | Автоматическая обработка | Vercel Image API + Квотер |
| **Хранение** | Надежное хранение | S3 (Storj + AWS) |
| **Доставка** | Глобальный CDN | Vercel Edge Network |

## 📤 Загрузка файлов

### Поддерживаемые форматы
- **Изображения** — JPEG, PNG, GIF, WebP, HEIC
- **Аудио** — MP3, WAV, FLAC, OGG
- **Видео** — MP4, WebM, MOV
- **Документы** — PDF, DOC, TXT

### Процесс загрузки
1. **Валидация** — проверка типа и размера файла
2. **Оптимизация** — сжатие и конвертация формата
3. **Хранение** — загрузка в облачное хранилище
4. **Индексация** — добавление в поиск и рекомендации

### Ограничения
- **Максимальный размер** — 500MB для всех типов файлов
- **Изображения** — автоматическая конвертация в JPEG
- **Видео** — ограничение длительности и разрешения

## 🖼️ Оптимизация изображений

### Автоматическая обработка
```typescript
// Автоматическая оптимизация через Vercel Image API
const optimizedUrl = getOptimizedImageUrl('image.jpg', {
  width: 600,
  quality: 75
})
// Результат: /_next/image?url=https://files.dscrs.site/image.jpg&w=600&q=75
```

### Квотер оптимизация
```typescript
// Резка изображений через Квотер
const quoterUrl = getQuoterWebpUrl('image.jpg', 600)
// Результат: https://files.dscrs.site/image_600.jpg/webp
```

### Поддерживаемые размеры
- **Миниатюры** — 64, 128, 256, 320px
- **Средние** — 400, 640, 800px
- **Крупные** — 1200, 1600px
- **Оригинал** — без ограничений

## 🎨 Open Graph изображения

### Динамическая генерация
```typescript
// Автоматическая генерация OG изображений
const ogUrl = `/api/og/article?title=${encodeURIComponent(title)}&author=${author}`
// Результат: динамическое изображение 1200x630px
```

### Типы OG изображений
- **Статьи** — заголовок, автор, тема
- **Авторы** — имя, биография, статистика
- **Темы** — название, описание, количество публикаций
- **Стандартное** — логотип платформы

## 📊 Производительность

### Метрики оптимизации
- **Скорость загрузки** — < 200ms для изображений
- **Размер файлов** — 25-50% экономия через WebP
- **Качество** — сохранение визуального качества
- **Кеширование** — глобальный CDN кеш

### Стратегии кеширования
- **Браузер кеш** — 7 дней для статических изображений
- **CDN кеш** — 1 год для оптимизированных изображений
- **Edge кеш** — мгновенная доставка по всему миру

## 🚨 Обработка ошибок

### Fallback стратегии
1. **Оригинальное изображение** — если оптимизация недоступна
2. **Заглушка** — стандартная иконка вместо изображения
3. **Альтернативный размер** — другой размер изображения
4. **Кешированная версия** — использование локального кеша

### Пользовательские сообщения
- **Превышение размера** — информирование о лимитах
- **Неподдерживаемый формат** — предложение альтернатив
- **Ошибка сети** — предложение повторить попытку
