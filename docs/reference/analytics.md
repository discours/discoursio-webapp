## 🏗️ Архитектура

### Основные компоненты

- GA4 как основной бекенд аналитики
- Интеграция через [gtag.js](src/lib/analytics/gtag.ts)
- Локальное кеширование для оптимизации
- Service Worker для оффлайн-режима

### Конфигурация

Конфигурация GA4 находится в [app.config.ts](src/config/analytics.ts):
- Measurement ID
- Настройки пользователей
- Параметры конфиденциальности

## Отслеживаемые метрики

### 1. Просмотры страниц
- Реализация: [PageView.tsx](src/components/Analytics/PageView.tsx)
- Автоматическое отслеживание через роутер
- Фильтрация служебных страниц

### 2. Взаимодействие с контентом
- Просмотры статей: [ArticleView.tsx](src/components/Analytics/ArticleView.tsx)
- Время чтения: [ReadingTime.tsx](src/components/Analytics/ReadingTime.tsx)
- Глубина прокрутки: [ScrollDepth.tsx](src/components/Analytics/ScrollDepth.tsx)

### 3. Пользовательские действия
- Регистрация/авторизация
- Комментарии и реакции
- Подписки и закладки

## Оптимизация производительности

### 1. Батчинг событий
- Группировка событий перед отправкой
- Дебаунсинг частых событий
- Очередь для оффлайн-режима

### 2. Кеширование
- Локальное хранение неотправленных событий
- Синхронизация при восстановлении соединения
- Управление размером кеша

## Конфиденциальность

### 1. Согласие пользователя
- Управление через [ConsentManager](src/components/Analytics/ConsentManager.tsx)
- Соответствие GDPR/CCPA
- Настройки хранения данных

### 2. Анонимизация
- IP-адреса
- Пользовательские идентификаторы
- Чувствительные данные

## Отладка и мониторинг

### 1. Режим разработки
- Логирование событий
- Проверка параметров
- Валидация данных

### 2. Мониторинг
- Отслеживание ошибок
- Производительность отправки
- Качество данных
