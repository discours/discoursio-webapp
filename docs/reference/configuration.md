## 🎯 Переменные окружения

Конфигурация приложения управляется через переменные окружения для гибкости развертывания.

### 🌐 API и сервисы

| Переменная | Описание | Значение по умолчанию |
|------------|----------|----------------------|
| `PUBLIC_CORE_API` | Основной GraphQL API | `https://v3.dscrs.site/graphql` |
| `PUBLIC_INBOX_API` | API для сообщений | `https://inbox.dscrs.site` |
| `PUBLIC_REALTIME_EVENTS` | SSE для уведомлений | `https://connect.dscrs.site` |
| `PUBLIC_CDN_URL` | CDN для файлов | `https://files.dscrs.site` |

| `PUBLIC_GLITCHTIP_DSN` | Error tracking | Не установлен |

## 🔒 Безопасность

### Рекомендации по настройке

#### HTTPS сертификаты
- **Автоматическая настройка** — mkcert для локальной разработки
- **Production сертификаты** — предоставляются платформой развертывания

#### API ключи
- **Хранение** — только в переменных окружения
- **Ротация** — регулярная смена ключей
- **Доступ** — минимальные необходимые разрешения

#### База данных
- **Пароли** — сильные уникальные пароли
- **Шифрование** — данных в покое и в транзите
- **Бэкапы** — регулярное резервное копирование

## 🔄 Обновление конфигурации

### Процесс обновления
1. **Тестирование** — проверка в staging среде
2. **Документирование** — обновление инструкций
3. **Развертывание** — применение в production
4. **Мониторинг** — наблюдение за метриками

### Резервные копии
- **Автоматическое резервное копирование** — ежедневно
- **Тестирование восстановления** — ежеквартально
- **Документирование** — процедуры восстановления
