## 📋 Категории форматирования

### 1. Блочное форматирование (Block-level)
**Условие применения**: Курсор находится в блоке (без выделения) ИЛИ весь блок выделен полностью

- **Параграфы**: `p`
- **Заголовки**: `h1`, `h2`, `h3`
- **Цитаты**: `blockquote`, `punchline`
- **Врезка (подвёрстка)**: `squib` (`div[data-align]`)
- **Списки**: `bulletList` (ul), `orderedList` (ol)
- **Разделители**: `hr`, `separator`

### 2. Инлайн форматирование (Inline)
**Условие применения**: Выделена ЧАСТЬ текста внутри блока

- **Текст**: `bold` (strong), `italic` (em)
- **Выделение**: `highlight` (mark), `data-bg` (цветные фоны)
- **Ссылки**: `link` (a), `unlink`, `tooltip`

### 3. Медиа элементы
- **Изображения**: `image`
- **Видео**: `video`
- **Аудио**: `audio`
- **Встраивание**: `embed`

### 4. Специальные атрибуты
- **Выравнивание врезки**: `align-left`, `align-center`, `align-right`
- **Фоны**: `bg-gray`, `bg-white`, `bg-black`, `bg-yellow`, `bg-red`, `bg-green`, `bg-color`

## 🎯 Критичные сценарии для тестирования

### Блочное форматирование

#### 1. Простые преобразования (весь блок)
```typescript
// Тест 1.1: p → h1 (курсор внутри, без выделения)
начало: "<p>текст|</p>"
команда: 'h1'
ожидание: "<h1>текст</h1>"

// Тест 1.2: p → h1 (весь текст выделен)
начало: "<p>[текст]</p>" (весь текст выделен)
команда: 'h1'
ожидание: "<h1>текст</h1>"

// Тест 1.3: p → h1 (частичное выделение) - НЕ ПРЕОБРАЗУЕТСЯ
начало: "<p>[тек]ст</p>" (выделена только часть)
команда: 'h1'
ожидание: "<p><h1>тек</h1>ст</p>" (inline, может быть некорректно) ИЛИ ничего не происходит

// Тест 1.4: h1 → h2
начало: "<h1>заголовок|</h1>"
команда: 'h2'
ожидание: "<h2>заголовок</h2>"

// Тест 1.5: h1 → p (toggle)
начало: "<h1>заголовок|</h1>"
команда: 'h1'
ожидание: "<p>заголовок</p>"
```

#### 2. Squib (врезка)
```typescript
// Тест 2.1: p → squib (курсор внутри)
начало: "<p>текст|</p>"
команда: 'squib'
ожидание: "<div data-align=\"left\">текст</div>"

// Тест 2.2: p → squib (весь текст выделен)
начало: "<p>[текст]</p>"
команда: 'squib'
ожидание: "<div data-align=\"left\">текст</div>"

// Тест 2.3: squib → p (toggle)
начало: "<div data-align=\"left\">текст|</div>"
команда: 'squib'
ожидание: "<p>текст</p>"

// Тест 2.4: squib → h1 (смена блока)
начало: "<div data-align=\"left\">текст|</div>"
команда: 'h1'
ожидание: "<h1>текст</h1>"

// Тест 2.5: squib + выравнивание (курсор внутри)
начало: "<div data-align=\"left\">текст|</div>"
команда: 'align-center'
ожидание: "<div data-align=\"center\">текст</div>"

// Тест 2.6: squib + inline форматирование (частичное выделение)
начало: "<div data-align=\"left\">[текст]</div>" (выделена часть)
команда: 'bold'
ожидание: "<div data-align=\"left\"><strong>текст</strong></div>"

// Тест 2.7: НЕ преобразовывать squib при частичном выделении
начало: "<div data-align=\"left\">один [два] три</div>"
команда: 'h1'
ожидание: "<div data-align=\"left\">один [два] три</div>" (без изменений блока)
```

#### 3. Списки
```typescript
// Тест 3.1: p → ul (курсор внутри)
начало: "<p>элемент|</p>"
команда: 'bulletList'
ожидание: "<ul><li>элемент</li></ul>"

// Тест 3.2: ul → ol (курсор внутри li)
начало: "<ul><li>элемент|</li></ul>"
команда: 'orderedList'
ожидание: "<ol><li>элемент</li></ol>"

// Тест 3.3: ul (один li) → p (toggle)
начало: "<ul><li>элемент|</li></ul>"
команда: 'bulletList' (toggle)
ожидание: "<p>элемент</p>"

// Тест 3.4: ul (много li) → сохранить структуру
начало: "<ul><li>элемент 1|</li><li>элемент 2</li></ul>"
действие: курсор на первый li, toggle bulletList
ожидание: список сохранен (не убирается если > 1 элемента)

// Тест 3.5: НЕ преобразовывать список при частичном выделении
начало: "<ul><li>элемент [один] два</li></ul>"
команда: 'h1'
ожидание: "<ul><li>элемент [один] два</li></ul>" (без изменений)
```

### Вложенное форматирование (Nested)

#### 6. Block + Inline комбинации
```typescript
// Тест 6.1: bold внутри h1 (частичное выделение = inline)
начало: "<h1>[заголовок]</h1>" (только текст выделен, не весь блок)
команда: 'bold'
ожидание: "<h1><strong>заголовок</strong></h1>"

// Тест 6.2: h1 → h2 с сохранением bold (курсор внутри = block)
начало: "<h1><strong>заголовок|</strong></h1>"
команда: 'h2'
ожидание: "<h2><strong>заголовок</strong></h2>"

// Тест 6.3: squib с bold + italic → p (курсор = block)
начало: "<div data-align=\"left\"><strong>жирный|</strong> <em>курсив</em></div>"
команда: 'squib' (toggle)
ожидание: "<p><strong>жирный</strong> <em>курсив</em></p>"

// Тест 6.4: blockquote с ссылкой → p (курсор = block)
начало: "<blockquote>текст с <a href=\"#\">ссылкой|</a></blockquote>"
команда: 'blockquote' (toggle)
ожидание: "<p>текст с <a href=\"#\">ссылкой</a></p>"

// Тест 6.5: squib с highlight (курсор = изменение align)
начало: "<div data-align=\"center\">текст с <mark>выделением|</mark></div>"
команда: 'align-right'
ожидание: "<div data-align=\"right\">текст с <mark>выделением</mark></div>"

// Тест 6.6: список с bold → p (курсор = block)
начало: "<ul><li><strong>жирный|</strong> элемент</li></ul>"
команда: 'bulletList' (toggle, один li)
ожидание: "<p><strong>жирный</strong> элемент</p>"

// Тест 6.7: punchline с форматированием → p (курсор = block)
начало: "<div data-type=\"punchline\"><em>Важная|</em> <strong>мысль</strong></div>"
команда: 'punchline' (toggle)
ожидание: "<p><em>Важная</em> <strong>мысль</strong></p>"

// Тест 6.8: НЕ преобразовывать block при частичном inline выделении
начало: "<h1>начало [середина] конец</h1>"
команда: 'blockquote'
ожидание: "<h1>начало [середина] конец</h1>" (блок не меняется)
```

```typescript
команда: 'align-left'
ожидание: "<div data-align=\"left\"><a href=\"#\">ссылка</a> и <mark>выделение</mark></div>"

начало: "<h1><strong>Жирный</strong> <em>курсив</em> <a href=\"#\">ссылка</a></h1>"
команда: 'blockquote'
ожидание: "<blockquote><strong>Жирный</strong> <em>курсив</em> <a href=\"#\">ссылка</a></blockquote>"

// Тест 7.4: blockquote с data-bg внутри
начало: "<blockquote>текст с <span data-bg=\"yellow\">желтым фоном</span></blockquote>"
команда: 'punchline'
ожидание: "<div data-type=\"punchline\">текст с <span data-bg=\"yellow\">желтым фоном</span></div>"

команда: 'h2'
```

#### 8. Частичное выделение с inline форматированием

```typescript
// Тест 8.4: частичное удаление bold
начало: "<blockquote><strong>жирный текст</strong></blockquote>"
```


## 🔍 Известные проблемы

### Текущие баги (требуют исправления)
1. ❌ Squib menu не появляется после создания squib
2. ❌ Кнопка squib не видна в dropdown (возможно, ошибка иконки)
3. ⚠️ Plus menu позиционирование может быть некорректным в некоторых случаях
4. ⚠️ Floating toolbar может перекрывать текст

### Edge cases (требуют тестирования)
1. ✅ **Вложенное форматирование**: inline внутри block (добавлено в матрицу)
2. ⚠️ Вложенные списки (ul внутри li)
3. ⚠️ Squib с несколькими параграфами внутри
4. ⚠️ Длинные заголовки с переносом строк
5. ⚠️ Множественное выделение (если поддерживается)
6. ⚠️ Вставка из буфера обмена с сохранением форматирования

## 📊 Приоритеты тестирования
