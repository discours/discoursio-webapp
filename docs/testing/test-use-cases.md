## 🔄 Процесс тестирования

### Автоматизированное тестирование
- **E2E тесты** - Playwright для проверки пользовательских сценариев
- **Unit тесты** - Тестирование отдельных компонентов
- **Integration тесты** - Проверка взаимодействия компонентов

### Ручное тестирование
- **Exploratory testing** - исследовательское тестирование новой функциональности
- **Usability testing** - тестирование удобства использования
- **Accessibility testing** - проверка доступности

### Регрессионное тестирование
- **Smoke тесты** - быстрая проверка основной функциональности
- **Regression suite** - полный набор тестов перед релизом
- **Performance testing** - проверка производительности
