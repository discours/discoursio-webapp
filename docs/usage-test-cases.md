# Тест-кейсы для Discours.io: Test-Driven Development (TDD)

### 1. Создание, публикация и редактирование материалов

#### Сценарии тестирования
- Успешное создание публикации всех форматов:
  - Статья
  - Музыка
  - Литература
  - Видео

- Сохранение черновика в списке черновиков пользователя
- Публикация материала с минимально допустимыми данными:
  - Заголовок
  - Тело
  - Заглавная тема

- Редактирование опубликованного материала:
  - Изменение текста
  - Обновление обложки
  - Правка slug-адреса
  - Изменение тем

- Загрузка медиафайлов:
  - Аудио
  - Видео
  - Изображения

- Обработка ошибок при загрузке:
  - Неподдерживаемый формат файла
  - Превышение максимального размера файла

### 2. Переходы на страницы тем

#### Сценарии тестирования
- Клик по теме:
  - В меню на главной странице
  - Под публикациями
  - На странице всех тем

- Проверка страницы темы:
  - Отображение всех связанных публикаций
  - Фильтрация публикаций:
    * По дате
    * По рейтингу
    * По формату

- Корректность загрузки страниц тем при прямом переходе по URL

### 3. Регистрация и авторизация

#### Регистрация через email
- Успешная регистрация нового пользователя
- Обработка ошибок:
  - Email уже используется
  - Слабый пароль
  - Некорректный email

- Авторизация зарегистрированного пользователя
- Сброс пароля по email

#### Авторизация через внешние сервисы
- Успешная авторизация:
  - Google
  - Facebook
  - VK
  - GitHub

- Обработка отмены авторизации
- Создание нового аккаунта при первом входе
- Импорт данных профиля:
  - Имя
  - Email
  - Аватарка

- Повторная авторизация через внешний сервис в существующий аккаунт

### 4. Комментарии

#### Сценарии тестирования
- Написание нового комментария
- Ответ на комментарий (древовидная структура)
- Редактирование собственного комментария
- Удаление собственного комментария
- Обработка пустого комментария
- Обновление списка комментариев:
  - В реальном времени
  - После обновления страницы

### 5. Профили пользователей

#### Сценарии тестирования
- Переход в профиль по имени автора
- Просмотр в профиле:
  - Публикаций
  - Комментариев
  - Подписок на темы
  - Подписок на авторов

- Различное отображение профилей:
  - Собственный профиль
  - Профиль другого пользователя

- Отображение статистики:
  - Количество подписчиков
  - Количество подписок

### 6. Подписки

#### Сценарии тестирования
- Подписка/отписка на автора:
  - На странице автора
  - Под публикацией

- Подписка/отписка на тему
- Отображение в профиле:
  - Подписанных тем
  - Подписанных авторов

- Push/уведомления о новых публикациях

### 7. Редактирование профиля

#### Сценарии тестирования
- Загрузка и обновление аватарки
- Редактирование:
  - Имени
  - Биографии
  - Ссылок

- Проверка ограничений длины полей
- Сброс изменений
- Сохранение изменений

### 8. Рейтинг и оценка

#### Сценарии тестирования
- Отображение суммарного рейтинга:
  - Под публикациями
  - Под комментариями

- Взаимодействие с рейтингом:
  - Просмотр списка проголосовавших
  - Отображение аватаров
  - Ссылки на профили

- Изменение рейтинга:
  - Плюс/минус под публикацией
  - Плюс/минус под комментарием
  - Отмена голоса повторным нажатием

- Ограничения:
  - Оценки доступны только авторизованным пользователям

### 9. Лента

#### Сценарии тестирования
- Раздел «Все»:
  - Отображение всех опубликованных материалов

- Раздел «Моя лента»:
  - Материалы от подписанных авторов
  - Материалы по подписанным темам

- Сортировка материалов:
  - По дате публикации
  - По рейтингу
  - По дате последнего обновления

- Фильтрация материалов:
  - По периоду публикации
  - По статусу (все/зафичеренные/незафичеренные)

### 10. Поиск

#### Сценарии тестирования
- Поиск по ключевому слову:
  - В названии
  - В тексте
  - По автору
  - По теме

- Обработка пустого запроса
- Нечёткий поиск:
  - Опечатки
  - Транслитерация
  - Регистр

- Фильтры по формату:
  - Статья
  - Музыка
  - Другие форматы

- Переход из результатов поиска в материал

### 11. Страница «Все авторы»

#### Сценарии тестирования
- Отображение списка авторов:
  - Актуальная статистика
  - Ссылки на профили

- Сортировка списка:
  - По количеству публикаций
  - По количеству подписчиков
  - По имени (алфавитный порядок)

### 12. Страница «Все темы»

#### Сценарии тестирования
- Отображение списка тем:
  - Актуальная статистика

- Сортировка списка:
  - По количеству публикаций
  - По количеству подписчиков
  - По названию (алфавитный порядок)
