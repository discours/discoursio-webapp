# 🚀 Деплой и развертывание

## 🎯 Стратегия развертывания

Автоматизированное развертывание обеспечивает надежность и скорость доставки.

### 🌐 Платформы развертывания

| Платформа | Назначение | Автоматизация |
|-----------|------------|---------------|
| **Vercel** | Production | Автоматический деплой |
| **Netlify** | Альтернатива | Ручная настройка |
| **Docker** | Контейнеры | Локальная разработка |

### 🔄 Процесс деплоя

#### Автоматический деплой
- **main** → production (Vercel)
- **dev** → staging для тестирования
- **PR** → preview для ревью кода

#### Ручной деплой
```bash
npm run build       # Сборка для продакшена
npm run preview     # Локальный предпросмотр
```

## ⚙️ Конфигурация

### Vercel настройка
```json
{
  "framework": "solidstart",
  "buildCommand": "npm run build",
  "installCommand": "npm ci",
  "outputDirectory": ".output",
  "functions": {
    "api/og.js": {
      "runtime": "edge"
    }
  }
}
```

### Переменные окружения
```bash
# API
PUBLIC_CORE_API=https://v3.dscrs.site/graphql
PUBLIC_INBOX_API=https://inbox.dscrs.site

# CDN
PUBLIC_CDN_URL=https://files.dscrs.site

# Аналитика
PUBLIC_GA_IDENTITY=G-LQ4B87H8C2

# Безопасность
TOKEN_REFRESH_INTERVAL=30
```

## 📊 Мониторинг

### Метрики развертывания
- **Время сборки** — < 3 минут
- **Размер бандла** — < 400KB gzipped
- **Core Web Vitals** — все в зеленой зоне
- **Доступность** — 99.9% uptime

### Логи и отладка
```bash
# Локальные логи
npm run dev

# Продакшн логи (Vercel)
vercel logs --follow

# Функции (Edge Functions)
vercel logs --function=og
```
