## Неопубликованные изменения

### Добавлено
- Индикатор подключения к серверу рядом с селектором режима редактирования
- Улучшенная всплывающая подсказка для индикатора подключения с информацией о состоянии
- Возможность ручного переподключения к серверу при клике на индикатор, когда соединение отсутствует
- Новый пользовательский интерфейс для элементов управления редактированием (размещены в одну строку)

### Исправлено
- Улучшена обработка ошибок при отправке обновлений awareness при отсутствии подключения
- Добавлено корректное сохранение изменений в локальное хранилище при отсутствии подключения
