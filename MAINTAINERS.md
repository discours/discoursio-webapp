Git history includes many contributors. This file lists current decision-making responsibility, not authorship or ownership of every part of the codebase.

## Responsibilities

Maintainers triage contributions, protect user and contributor safety, keep the default branch buildable, document product or architecture decisions, and decide releases and deployment separately from code review.

## Decision model

- Small, reversible implementation choices are resolved in review.
- Product behaviour, public contracts, security posture, data handling, and deployment changes require explicit maintainer agreement.
- A merged change does not by itself mean that a release or deployment occurred.

## Adding maintainers

Regular contributors may be invited after sustained, reviewable work and demonstrated care with security, editorial context, accessibility, and contributor communication. Repository permissions are granted separately and should follow least privilege.
