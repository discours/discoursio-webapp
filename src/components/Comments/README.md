## Структура компонентов

- `CommentCard` - компонент карточки комментария, используется в `CommentsTree` b
- `CommentDate` - компонент даты комментария, используется в `CommentCard`
- `CommentsList` - компонент списка комментариев, используется в `AuthorView`
- `CommentsHeader` - компонент заголовка списка комментариев, используется в `CommentsTree`
- `CommentsTree` - компонент древовидного списка комментариев, используется в `AuthorView`
